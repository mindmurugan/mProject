# Hearth

A private, shared lifestyle & household app — SwiftUI + SwiftData + CloudKit
sharing, built for two people on two separate iCloud accounts.

Start here: [`docs/ARCHITECTURE.md`](docs/ARCHITECTURE.md) — project layout,
architecture decisions, and the phase-by-phase build plan.

```sh
brew install xcodegen
cd Hearth
xcodegen generate
open Hearth.xcodeproj
```

"Hearth" and all bundle/container identifiers are placeholders — see
[Renaming](docs/ARCHITECTURE.md#6-renaming--things-you-must-change-before-building)
before your first build.
